# 明知AI剪辑 · 宣传片设计规格（三方向共同输入）

## 产品是什么
「明知AI剪辑」（英文 Mingzhi）是一个开源（MIT）、在自己电脑上运行的口播 AI 剪辑工作台。博主只录一条竖屏口播，丢进去：本机识别字幕（音频不出本机）→ AI 剪掉口误和气口 → 抠像换背景（10 种预设场景）→ 自动分镜，上半屏信息卡、下半屏人像 → 自动配 B-roll、卡片动画、转场 → 配乐音效、统一响度 → 生成 4:3/3:4 封面 → 卡片视觉自检与成片硬检查 → 出一条可直接发布的 9:16 成片。之后不用剪辑软件，**用一句话对话修改**（「背景换成夜景落地窗」「@00:29 这张卡太弱了」），每轮出新版本（v1→v2→v3），只重渲改动的镜头，可双版本对比、回退、导出。整个过程会实时播放「剪辑直播」：转录逐行出现、口误被划掉、分镜逐张出现、自检分数跳出、花费实时跳动，例如「样片实花 ¥3.76」。

## 受众与场景
知识类口播博主、小团队运营、独立创作者。他们会剪辑但讨厌重复劳动：剪气口、加字幕、找素材、做封面，一条视频要磨两三个小时。看片的场景是产品发布页的 hero 视频、B 站或小红书的发布片、GitHub README 顶部的动图。

## 核心信息（按优先级）
1. 一条口播进去，一条成片出来（「把一条口播，变成 *finished cut*」，这是工作台首屏的原句）
2. 不是剪辑软件：没有时间线和轨道，用一句话改
3. 每次修改只重渲改动的那一段，几秒钟出新版本，可以并排对比
4. 在你的电脑上运行，音频不出本机，开源免费（模型按量付费，一条约几块钱）

## 情感基调
明亮、安静、精致、友好，带一点惊喜：从「乱糟糟的原片」到「干净的成片」的爽感。是「被照顾」而不是「被炫技」，参照 ego (lite)、Apple 产品片里那种克制的自信。

## 输出格式与尺寸（三版必须统一）
- 方向板：1920×1080（16:9）单张静帧 HTML。画面主体是这支片的 hero 关键帧，下方或侧边留一条窄带，放色板条、一句气质定位和参照作品名。
- 成片计划：16:9 主版约 45–60 秒，之后另出 9:16 版本。带配乐与音效，不配旁白，字幕卡片承载文案，中文。

## 品牌资产（必须使用，在 `promo/assets/` 下）
- 产品 UI 截图（测试模式，画面是合成样片，没有真人）：`assets/ui/*.png`，1440×900。包括剪辑直播重播态、v1 出片中直播态、双版本对比态、设置卡、对话修改出新版本。
- 招牌油画（印象派，gpt-image 生成）：`assets/art/01-studio.webp`（书房 + 三脚架相机）、`02-garden.webp`（花园露台）、`03-cinema.webp`（小影院）；`silhouette.webp` 是无面孔磨砂玻璃半身像。
- 封面风格示例：`web/public/covers/*.webp`（10 种，无真人）。背景预设：`assets/backgrounds/*.jpg`（10 种场景，无人）。
- 视觉 token（照抄 G1）：背景 #fff/#f7f7f7/#f5f5f5/#eee/#e0e0e0；文字 #000000e6/#000000b3/#0000008f；品牌蓝阶 #d6dff5 #adc0eb #85a0e0 #5c81d6 #3361cc #294ea3；主 CTA 黑胶囊，次 CTA #eee 胶囊；关键短语浅蓝胶囊 #d6dff5 底配 #294ea3 字；斜体衬线点缀用 IBM Plex Serif Italic 200（只用于数字、拉丁文和括号小注，例如「(只花 ¥3.84)」「finished cut」）；终端用 IBM Plex Mono；中文正文用 system-ui / PingFang SC。
- 标志：黑色圆形里一个白色「明」字（见工作台左上角）。

## 禁区
- 不出现任何真人面孔（作者本人的口播素材不能用）。需要「人在说话」的画面时，用无面孔剪影、背影、手部特写，或明确是 AI 生成的虚构人物（生成时注意不像任何真实名人）。
- 不用紫色渐变、霓虹科技风、emoji 图标、SVG 手画人物。
- 不编造数据：数字只用真实数据（样片实花 ¥3.76；剪口误 2 处，2:12→2:02；换背景合成 5.8 秒、原来 35 秒；改节奏 61 秒→1.8 秒；7 项成片检查全过）。

## 视觉母题假设（每版可以推翻，但要说明理由）
- 「划掉」：转录文字里的口误被一笔划掉，是剪辑最直观的隐喻
- 「浮窗立在画上」：9:16 白色浮窗立在一幅油画上，人在画里生活、成片在画上诞生
- 「v1 → v2」：版本号胶囊像翻页一样递进，只有改动的一段亮起蓝点
- 「一句话」：输入框里打一句中文，整条片随之改变

## 录屏感要求
画面里要有「真的在用」的感觉：光标移动和点击、输入框逐字打出、进度条推进、终端逐行打印、数字滚动。可以用 HTML 重建 UI（推荐，清晰可控），也可以对截图运镜。
