## 0 · 一句话概念

**一条口播是一局关卡：白色小象踩掉口误、穿过换背景的传送门、顶出分镜卡、听你一句话只重修一段、插上 v2 存档旗，最后走进影院，看自己的成片上映。**

片中只有一个动作母题：**踩**。口误被踩扁，地砖自己合缝。这就是「剪掉」。

规格：16:9 主版 1920×1080 · 30fps · **53.0 秒 · 14 镜** · 无旁白，文字卡承载文案，中文 · 高潮在 41.5s（不在结尾）。

## Part I · Director's Statement

### 1. 这支片不是什么

- 它**不是功能介绍片**。功能清单（7 个阶段、10 种背景、4:3/3:4 封面……）一次都不会念出来，观众只看见小象在一个关卡里经历了什么。
- 它**不是赛博科技片**。没有发光粒子、没有深蓝底霓虹、没有数据流。科技感来自真实的产品界面截图，以及真实发生的数字。
- 它**不是复古游戏的戏仿**。像素在这里不为怀旧，它是一个论证：印象派油画的笔触本来就是色块，降采样到 8px 就成了像素。我们的「世界」就是工作台里那几幅招牌油画，像素化之后成了关卡。所以这支片的复古只到质感为止，节奏、排版和留白都按今天的产品片来做。
- 它**不是「AI 一键魔法」**。每一步都给过程：转录一块块翻面，口误要一只只踩，重渲有扫描线，存档要插旗。spec 要的是「被照顾」的感觉，「被炫技」的感觉不要。

### 2. 核心 thesis（观众只记一句）

**「把一条口播，变成 finished cut.」** 这是工作台首屏原句，也是片尾唯一的大字。片中其余文案都是这句话的注脚。

### 4. 三类观众与承诺

- **主受众：知识类口播博主、小团队运营。** 他们会剪辑，讨厌重复劳动。承诺：前 16 秒你就能看到最烦的那件事（剪气口和口误）被一脚踩掉，时间从 2:12 变成 2:02。
- **次受众：GitHub / 开发者。** 他们关心能不能跑、开不开源、数据去哪。承诺：「音频不出本机」出现在第 7 秒；片尾的 GitHub 地址和 MIT 停留 ≥2 秒，能截图。
- **外受众：路过的设计圈 / 小红书用户。** 他们只看几秒。承诺：任何一帧暂停都是一张能单独发出去的海报（封面测试），高潮那帧（S12 影院）就是封面。

### 5. 节奏哲学

慢开（3s 降采样 + 3.5s 落地）→ 中速爬升（踩、合缝、穿门、顶卡，高低交替）→ **25s 一张白色呼吸卡把能量降到底** → 第二段从一句话重新起势（这是产品真正的差异点，必须在观众最清醒的时候出现）→ 存档 → **41.5s 影院放映为全片情绪顶点** → 结算与片尾缓收，结尾 5 秒全景 hold。

### 6. 这支片不做的事（anti-slop）

1. 不出现任何真人面孔；剪影只用 spec 提供的无面孔磨砂半身像，影院观众只有背影。
2. 不用 emoji、不用 SVG 手画人物、不用紫色渐变、不用霓虹发光。
3. 不编造数字：全片只出现 ¥3.76、口误 2 处、2:12→2:02、5.8s/35s、61s→1.8s、7/7 六组数字；截图里的其他数字（如「本段自检 8.9」「00:50」）一律用 HTML 补丁盖掉。
4. 不在像素世界里用非整数缩放（只允许 1x / 1.5x / 2x），不让像素格糊成马赛克。
5. 不同时动两件事：镜头在动时 UI 不切状态，UI 在变时镜头锁死。
6. 不做 fade-in 的 logo；片尾 logo 由结算格坍缩成蓝块再展开。
7. 不渐隐收尾，最后一帧是清晰的全景 hold。
8. 不在同一接缝叠两种转场；全片零裸切。
9. 不让精灵变形走样：小象轮廓锁定 logo，只有腿、鼻尖、眼睛三处可以动。
10. 不把用户打字做成 AI 流式（用户输入 = 逐字符 3f；AI 回复 = chunk 涌现）。

### 3. 网格与像素规范

- **逻辑分辨率 320×180，像素格 6px**：精灵、地砖、方块、旗、彩纸、HUD 齿边都落在 6px 网格上（位置也取 6 的倍数）。
- **油画世界 8px 一格**（全景 405×135 格 = 3240×1080），**原片态 16px 一格**（203×68 格）。分辨率翻倍就是「原片 → 成片」的视觉论证。
- **变焦只有三档：1x / 1.5x / 2x**。6px 格在 1.5x 下是 9px，2x 下是 12px，都是整数屏幕像素。这一条覆盖 camera-language.md 的 1.3/1.45/1.8 档位，原因写在这里：像素片不能有非整数格。唯一例外是 S12 的 three.js 透视 dolly（像素格随深度连续变化，那是一次有意识的「走进空间」）。
- 安全区：四边 96px（5%）；HUD 高 64px + 6px 齿边；地平线 y=840（78%），与油画地面线对齐；第二行淡砖 y=900，砖土 y=960–1080。
- 镜头平移量取 6px 的倍数（1x）或 3px 的倍数（2x），防止像素抖动。

### 4. 油画 → 像素的降采样方案（已实现：`storyboard/tools/pixelize.py`）

1. `Image.BOX` 降采样到格子分辨率（BOX = 每格取平均色，等于把笔触压成色块）。
2. 中值切分量化，**不抖动**（抖动会把笔触变成噪点）：彩色世界 64 色，原片 12 色，预设背景 32 色，影院 64 色。
3. 彩色世界先做饱和度 ×1.18、对比 ×1.06，抵消量化后的发灰。
4. 原片态：饱和度 ×0.12、对比 ×0.72、混入 18% 冷灰 `#969CA6`，再降到 16px。
5. 剪影（白色 + alpha 的磨砂半身像）只量化 alpha 为 4 档（0/110/180/235），叠在像素化的背景预设上，组成「下半屏人像」。
6. 前景视差层用品红键抠像（`r−g>70 且 b−g>50` 视为透明）。
7. 输出小图，页面里用 `image-rendering: pixelated` 按整数倍放大。成片在 Remotion 里用同一批 PNG。

### 6. 英雄：像素小象规格

- **来源**：`assets/brand/logo-512.png` 白色区域 BOX 降采样到 24×22，再手修台阶。描边由程序按 4 邻域自动生成（像素墨 1 格），底边自动加 1 格阴影 `#d8e1f7`，眼睛 2×2 `#014DF9`。

- **朝向**：头朝右，全片向右行进（与阅读方向、进度方向一致）。
- **锁定**：背部斜线、头、鼻柱、倒 V 腿缝、拱形腹下，这五个轮廓特征任何帧都不改。只允许动三处：腿（下 3 行）、鼻尖（最后 1 行）、眼睛。

### 7. 动画系统

- **Easing（4 条，motion 的纯函数版，在 Remotion 里按帧求值）**：
  - `expoOut` = `cubicBezier(0.16,1,0.3,1)`：面板、卡片、计分牌入场（主 easing）
  - `overshoot` = `cubicBezier(0.34,1.56,0.64,1)`：方块被顶起、存档旗弹出、版本胶囊翻页
  - `camInOut` = `cubicBezier(0.65,0,0.35,1)`：所有推拉（时长走 `0.55×|ln(z2/z1)|/ln2`，1x→1.5x = 0.32s，1x→2x = 0.55s）
  - `follow` = `cubicBezier(0.33,0,0.15,1)`：跟拍小象的横移
- **混合帧率**：精灵、像素特效、旗帜飘动按 4f 一步（7.5fps）；镜头、产品 UI、数字滚动按 30fps 平滑。像素层所有位移在输出前取 6px 整数倍。
- **Duration 字典**：微交互 6–9f；面板入场 12f；卡片飞行 18f；镜头推拉 10–17f；关键结果前悬停 15f（0.5s）；批量动效收尾静止 15f。
- **Stagger**：地砖翻面 3f/块（正好跟打字同节奏）；CHECK 色块 4f/格；结算格 6f/格。
- **打字**：用户输入 3f/字符，打字时光标常亮，打完转 16f 周期闪烁；S09 预写一次退格（多打「了」→停 5f→退格→再打）。AI 回复按 2–5 字 chunk 涌现，间隔 40–120ms，用种子随机。

### 9. 视觉密度条款（验收标准）

**验收句：任意暂停一帧，跟方向板 `A-roulette-pixel.png` 并排放，不丢人。** 每一帧（呼吸卡 S08 与片尾 S14 除外）必须同时满足：

1. **世界层**：一幅像素化油画（不能是纯色底），且至少两层视差（世界 + 地面，彩色世界再加前景叶子）。
2. **真实内容**：地砖上是真实转录文字，UI 是真实截图裁切或按截图逐区块重建，不出现灰条假文字。
3. **状态层**：HUD 当前数值与这一镜的剧情一致（口误 0/2→1/2→2/2，TIME 2:12→2:02，CHECK 逐格点亮，STAGE v1→v2）。
4. **英雄在场**：小象在画面里，且姿势和这一镜的动作对应（不能永远站桩）。
5. **至少 1 个 idle 微动**：眨眼、光标闪、旗面 2 帧飘、彩纸下落、波形砖跳动，任选其一。
6. **同屏活跃元素 ≤3**：英雄组 + 1 个文字面板 + 1 个 UI/特效组。新元素进场，旧的先退。

| **Remotion**（选用） | ✅ | ① 产品本身的成片渲染就是 Remotion 4.0.531（仓库 `package.json`），宣传片用同一个引擎渲，片尾那句 RENDERED WITH REMOTION 是真话；② 用户指定 React + motion + three.js，Remotion 原生 React，`@remotion/three` 把 three 的时钟交给 `useCurrentFrame`；③ 逐帧 seek 渲染，结果确定 |
| HyperFrames | 备选，不用 | 它是 GSAP 时间轴范式，会在项目里引入第二套动画栈；本片 3D 只有 S12 一镜，Remotion 足够 |
| motion（framer） | ✅ 只当纯函数用 | 只用 `cubicBezier`、`spring` 生成器在帧号上求值，**不用** motion 组件的运行时动画循环（那是墙钟驱动，渲染不确定） |
| three.js | ✅ 只用在 S12（影院三层 dolly）+ S06 转轮（可选，3D 圆柱转轮） | 版本 pin `three@0.169.0`、`@react-three/fiber@8.17.10`、`@remotion/three@4.0.531`（都早于两周前发布） |

**确定性约定**：所有状态都是 `frame` 的纯函数；禁 `Math.random()`、`Date.now()`、CSS transition、`requestAnimationFrame`；随机一律用 mulberry32 种子（静帧源码里的 `seeded()` 已是此实现）；精灵帧号 = `Math.floor(frame/4) % N`；像素层位移 `Math.round(x/6)*6`；字体用 `@remotion/fonts` 的 `loadFont` 加载本地文件（Fusion Pixel woff2、Press Start 2P、IBM Plex 来自 `@fontsource`），等字体加载完再渲染（`delayRender`）。

**工程位置**：新建独立工程 `promo/film/`（自己的 `package.json`，pin 上述版本），不改仓库 `src/`、`web/`、`render/`。分镜静帧的 HTML 构件（`storyboard/frames.html` 里的 `sprite / elephant / ground / hudbar / uiWin / portrait` 等）一比一翻译成 React 组件。

### 2. Seedance（视频模型）用在哪

只用一处，**需要用户批准后才花钱**：让油画世界「活」起来，比如花园叶子轻摆、影院壁灯与银幕光微闪。做法是对全景图的花园段与影院段做图生视频（首尾帧同图 → 无缝循环 5s），再用 `pixelize.py` 同一套参数逐帧降采样、锁定调色板，作为世界层的 2–4 帧循环。

- 模型：`seed-2-mini` 720p 5s，约 ¥0.83/条（kkhub 价目）；2 条 + 1 次重试 ≈ ¥2.5。
- 提示词（花园段）：「这幅印象派油画里的花园轻微地动：前景的叶子和天竺葵被微风吹得轻轻摇摆，阳光的光斑在石地上缓慢移动；镜头完全固定，不推不移；画面风格、笔触、色彩保持不变；没有人、没有动物、没有文字」
- 提示词（影院段）：「这幅印象派油画里的复古影院：壁灯的暖光轻微闪烁，银幕上的光缓慢流动明暗；镜头完全固定；座位上没有任何人；笔触与色彩保持不变；没有文字」
- 不批准的替代：纯静态视差（当前静帧就是这个状态），成片质感会少一层「呼吸」。

### 3. 音乐与音效

**混合策略：两种声音 = 两个世界。** 游戏动作（跳、踩、顶砖、插旗、通关）用 8-bit 芯片音；产品动作（打字、点击、卡片吸附、扫描完成）用现代 UI 音。观众听觉上也能分清「游戏比喻」和「真产品」。8-bit 音效的音高统一调到 BGM 调内。

**BGM**：仓库已下载曲库 HoliznaCC0（OpenGameArt，**CC0 1.0**，清单 `assets/music.json`，文件在 `~/.mingzhi/assets/music/`）。曲库里没有真正的芯片音乐，选最接近的合成器复古曲：
- 首选 **Back in the 80s**（electronic / upbeat，240s，高频占比 0.19，最亮最合成器）

### 4. 9:16 版改编原则

1. **不是裁切，是重排**，而且直接借产品自己的 9:16 版式「上半屏信息卡、下半屏人像」：上 42% 是 HUD + 文字面板（等于信息卡），下 58% 是关卡（等于人像区），地平线在画高 82%。
2. 像素规格不变（6px / 8px 格），世界改用 GPT Image 2 的竖版关卡塔（提示词见 Part II-5），横向前进改成「横走 + 向上跳台阶」，每到一个新能力就上一层，这在竖屏里比纯横移更自然。
3. 9:16 的产品窗（传送门、分镜窗、对比窗、银幕成片）在竖屏里几乎满屏，是竖版的天然优势：S06、S11、S12 直接让窗口占画高 70%。
4. S10 的 14 段改成 2 排 × 7；S11 双窗改成上下叠 + 左右滑动对比；S13 bento 改成 2 列 × 3 行（¥3.76 占第一行整行）。
5. 文字放大 1.15 倍；底部 18%、右侧 12% 为平台按钮安全区（抖音 / 小红书 / 视频号），关键字一律不进。
6. 时长同为 53s；另出一条 30s 剪短版（S01、S02、S04、S05、S06、S09、S10、S12、S14），给信息流用。

### 工程（`promo/film/`）

- Remotion 4.0.531（与产品同一渲染引擎）+ React 18.3.1；motion 11.18.2 只当缓动函数库（`cubicBezier`）；three.js 0.169 + `@remotion/three` 渲染 S12 的 3D 彩纸（1/4 分辨率渲染再 4 倍像素放大）。remotion / react / renderer 复用仓库根目录依赖，`promo/film/node_modules` 只装 three 三件。
- 确定性：所有状态是帧号纯函数；随机用 mulberry32 种子；精灵 4 帧一步（on 4s）。
- 渲染：`node tools/render.mjs video Launch169|Launch916 <out.mp4>`（无声）→ `tools/mix.sh <无声.mp4> <成片.mp4>`；抽帧：`node tools/render.mjs stills Launch169 <帧号,...> <目录>`。
- 素材：`tools/sprites.py`（logo → 像素小象各姿势）、`storyboard/tools/pixelize.py`（油画 → 像素世界）、`tools/garden.py`（Seedance → 像素循环）。
