关于

    
    

      
明知AI剪辑 

      
开源的口播 AI 剪辑工作台。下面是会装到你电脑上的组件和它们的许可。

      

      
关于 FFmpeg 的 GPL 许可：这里用的 FFmpeg 是第三方按 GPL-3.0 发布的静态版本（含 x264 / x265 / libass）。明知AI剪辑只把它当独立程序调用，没有修改或链接它的代码；它的源码可在 ffmpeg.org 与各构建站点获取。

      
全部在本机运行：音频不上传，默认不收集任何数据。
