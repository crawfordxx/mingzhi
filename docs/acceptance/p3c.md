# P3c 配乐音效、响度、字幕样式与封面 · 验收记录（2026-10-15）

## 1. 结论
出片流程补齐「声音与包装」：
- **背景音乐**：自动选曲，说话时压低（-22 dB），停顿时抬起（-14 dB），开头淡入、结尾淡出。
- **卡片音效**：卡片入场、开关切换、CTA 点击、数字滚动、标签打勾、网页加载，时间点与模板动画逐帧对齐。
- **响度**：成片统一到 -14 LUFS（两遍 loudnorm；达不到目标时改用动态模式加限幅），带 faststart 方便网页播放。
- **字幕样式**：6 套，字体全部下载到本地（OFL 许可）。
- **封面**：用 GPT Image 2 按用户选的风格（10 种预设）生成 4:3 和 3:4 两张，Gemini 读图核对标题，人物用本地抠像合成，人脸不上传。

7 个任务逐个审查和修复，最后做了整分支终审。

## 4. 封面风格（10 种）
包豪斯（默认）、瑞士国际主义、孟菲斯、杂志极简、赛博霓虹、国潮、孔版印刷、新粗野主义、千禧 Y2K、日系清新。

- 每种风格各自规定：配色构图、留给人物的区域，以及人像的处理方式（描边、发光、硬投影或双色调）。
- 花费控制：
  - 标题核对**确实读到了错字**才重新生成，核对请求本身出错时不重生；
  - 已付费的底图会复用；
  - 先确认抠到了人，再去花钱生成底图。

## 5. 命令行
- `--bgm auto|none|<曲目id>`：配乐，默认 auto。
- `--caption-style <id>`：字幕样式，默认 blade。
- `--cover-style <id>`：封面风格，默认 bauhaus。
- `--no-cover`：不出封面。
- 素材没下载时：提示运行 `pnpm fetch-assets`，配乐降级为无配乐、字幕降级为系统字体。
- 封面失败时：只在进度里提示原因，不影响成片。
