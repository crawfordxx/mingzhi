## 3. 审查中确定的行为
- 分镜归一化：
  - 时间轴首尾相接、不重叠，从 0 开始、到片长结束；
  - 钩子卡只放在前 15 秒、最多 3 张，并重新编号；
  - CTA 固定在片尾，并吸收它后面的空镜头；
  - 带卡片的镜头限长 8 秒，余下部分补成全屏人像；
  - 短镜头如果并入后会超过 8 秒，就不合并；
  - 不可用的图片会被去掉；
  - `dropped`（无效镜头）和 `demoted`（被降级的卡片）分开统计。
- 模板拿到镜头时长：终端打字、划掉清单、开关点击都会在出场前做完。
- 标签卡按高度自动缩放，不会压进字幕区；文字宽度估算给大写字母和数字留了余量。
- CTA 固定为关注、点赞、收藏三连，颜色按文字匹配。
- 渲染：
  - 并发数不超过 CPU 核数；
  - publicDir 改用软链接，不再整目录复制，打包目录用完即清理；
  - 渲染失败时报中文错误。
- 分镜生成失败时，降级为全程人像，流程不中断；重试失败时保留第一次的结果，并在进度里注明。

## 4. 已知差距 / 延期
- **卡片和字号明显比参考片小**，上半屏米色留白太多；终审会给出具体的放大参数。
- 文字宽度是按 PingFang SC 估算的，P3c 打包字体后需要重新校准。
- CTA 的点击节奏不随镜头时长压缩（CTA 镜头一般较长）。
- 「镜头限长 8 秒」在真实模型输出上的表现，待充值后复验。
- B-roll（图片卡、浏览器卡的图片）还没有来源，放到 P3b；配乐、音效、响度、字幕样式和封面放到 P3c。
