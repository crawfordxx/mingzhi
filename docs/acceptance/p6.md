# P6 启动器与分发 · 验收记录（2026-10-16）

## 1. 结论
零技术用户的安装与启动链路已打通：
- **macOS**：下载 `Mingzhi-macos.zip`，解压后双击 `明知AI剪辑.command`。启动器是 arm64 + x86_64 通用二进制。
- **Windows**：双击 `Mingzhi.exe`。
- 两者都会出现一个终端或命令行窗口，同时自动打开浏览器：首次进入安装进度页，装好后跳转到工作台。关闭这个窗口即退出。
- 用户决定不做 `.app`，也不做无窗口的后台程序（2026-10-16）。

6 个任务逐个审查与修复，最后做了整分支终审，并完成两轮终审修复。

## 2. 组成
| 部分 | 实现 |
|---|---|
| 下载清单 | `launcher/manifest.lock.json` 锁定版本与 sha256，`scripts/build-manifest.mjs` 生成；国内镜像优先（npmmirror、hf-mirror、jsDelivr），GitHub 可填代理前缀 |
| 公开素材库 | [crawfordxx/mingzhi-assets@v1](https://github.com/crawfordxx/mingzhi-assets)：配乐 19 首（CC0，mp3）、4 款字体（OFL）、silero VAD（MIT）、RVM（GPL-3.0，附上游源码地址），经 jsDelivr 分发 |
| 启动器 | Rust 单文件，约 2.2 MB。支持续传、sha256 校验、多镜像回退、45 秒无数据换源、解包防穿越与解压上限、单实例、进度页（G1 视觉）、错误中文归类；配乐与字体为可选项，失败不阻塞并在后台补齐 |
| 应用本体 | 带源码目录 + 生产依赖 + tsx 启动，`mingzhi-app-<platform>.tar.zst`（darwin-arm64 47.3 MB，解压后 226 MB）；Chrome 装在 `runtime/`，由 `MINGZHI_CHROME` 指定 |
| 发布 | GitHub Actions 三平台矩阵（macos-14、macos-15-intel、windows-latest）。每个平台用启动器解包做烟测，并用安装好的 Chrome 实际渲染一张图；最后生成草稿 Release，附 sha256 与 THIRD_PARTY_NOTICES.md |
| 签名 | `scripts/macos-sign.sh` 读环境变量，缺失时跳过；本机只有 Apple Development 证书，只演练了签名、没有公证。`.command` 在去掉启动器的隔离标记前会先核对它的 sha256 |
| 更新与退出 | 每天最多匿名查询一次 GitHub Release，失败静默，可关闭；工作台设置可退出；无连接、无任务 2 小时后自动退出，睡眠唤醒不会误判 |

## 3. 端到端实测（macOS arm64，全新 AppRoot，按发布方式编译）
| 项 | 结果 |
|---|---|
| 本平台下载总量 | 621.5 MB（必需 468.5 MB + 可选 153 MB） |
| 首次安装到工作台就绪 | 约 12 分 13 秒（当天网速约 100–330 KB/s；配乐与字体约 13.8 分钟补齐），全程无出错、无重试 |
| 磁盘占用 | 约 1.1 GB（app 251 MB、runtime 380 MB、data 483 MB） |
| 二次启动 | 0.38–0.83 秒 |
| 退出 | Ctrl+C 0.21 秒；关闭终端窗口正常收尾；工作台退出 0.28 秒；强杀启动器后服务 0.06 秒内退出 |
| 再次双击 | 0.05 秒内交接给已运行的实例并打开浏览器 |
| 升级（模拟 0.1.1） | 只重下应用本体，7.5 秒就绪；项目数据保留；旧版本应用目录与旧缓存在后台清理 |
| 安全探测 | 伪造 Host 访问两个本机服务均返回 403，跨站退出请求返回 403 |

说明：主仓库目前还是私有的，应用包无法从 Release 匿名下载。所以实测时 app 包是预先放进下载目录的，其校验、解包和记录走的都是真实代码；其余 33 项全部联网下载。

## 4. 已知限制
- **Windows 真机未验证**：关闭控制台后能否在 3–5 秒内优雅退出、快速编辑模式是否已关闭、`rc.exe` 能否嵌入图标和版本信息，都要等第一次 Windows CI 或真机。
- **主仓库仍是私有**：要公开后 Release 才能匿名下载，更新检查也要等公开后才会生效。
- **未做公证**：没有 Developer ID 证书，首次打开需要按 README「首次打开」放行。
- **单源文件**：两款超过 20 MB 的字体和 SenseVoice 模型（228 MB）仍走原始来源。
