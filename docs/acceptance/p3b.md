# P3b B-roll 素材获取 · 验收记录（2026-10-15）

## 1. 结论
分镜卡片可以写「素材需求」：
- 钩子卡：生图或视频；
- 图片卡：截图或生图；
- 浏览器卡：截图。

出片时按「网页截图 > GPT Image 生图 > Pexels 图库 > Seedance 视频（只给开头钩子）」的优先级自动取齐素材，存进工作目录 `broll/`，写回分镜后交给 Remotion 渲染。图片卡和钩子卡支持视频素材：视频会循环播放，起点和镜头开头对齐。5 个任务都做了审查和修复，最后做了整分支终审。

## 2. 安全与可靠性（审查中修复）
- **截图只允许公网 http/https 地址**，以下都拒绝：
  - `file://`、`javascript:`；
  - 本机地址，包括 `localhost.`（末尾带点）和十进制、十六进制写法的 IP；
  - 内网与保留网段，包括 IPv4、IPv6，以及 IPv6 中内嵌 IPv4 的写法。

  检查只看地址写法本身，不做 DNS 解析，所以 DNS 重绑定和跳转不在防护范围内。
- 浏览器进程跨平台结束：Windows 用 `taskkill /T /F`，其他系统结束整个进程组。截图先写临时文件，检查不是空白页之后再改名。
- 网址提取兼容模型常见的写法：Markdown 链接、加粗、网址紧跟中文、全角标点、成对括号；同时去掉 `utm_*` 参数。
- 可想返回的花费是字符串（实测 `"0.6"`），在源头统一转成数字。
- 缓存：
  - 按素材需求的内容做规范化哈希，字段顺序不同也算同一份；
  - 重跑时直接命中缓存，不重复花钱；
  - 所有素材先写临时文件、确认非空后再改名，大小为 0 的缓存视为无效。
- 预算：
  - 每次付费前，按预估价检查（生图 ¥0.2、视频 ¥2.4）；
  - 接口没有返回花费时按预估价计费；
  - Seedance 按发起次数计入上限，失败也算。
- 单个素材失败不中断出片：
  - 图片卡拿不到素材时改为全屏人像；
  - 浏览器卡改为加载态；
  - 钩子卡改为纯色底；
  - 整个素材步骤出错时，按「不取素材」继续出片。

## 3. 命令行
`--no-broll`（关闭素材获取）、`--max-videos N`（默认 1）、`--budget 元`（默认 10）；Pexels 需要用户自己的 key（环境变量 `MINGZHI_PEXELS_KEY`），没有就跳过这一档。
