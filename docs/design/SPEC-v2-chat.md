# 明知AI剪辑 · 第二轮初稿 Spec（对话式布局）

> 内容素材、真实字幕、真实帧、受众、可读性底线、反 slop 规则，全部沿用 `SPEC.md`。本文件只覆盖**布局与交互范式**的变更。
> 事实更正：开源许可 **MIT**；语言模型用 **Gemini**（剪口误/分镜 gemini-3.5-flash，轻量 gemini-3.1-flash-lite）；ASR 为**本机 Paraformer**（音频不出本机）；生图 GPT Image 2；生视频 Seedance；算力平台「可想 AI」，余额 ¥36.27。不要出现 Claude Opus / 火山 / AGPL / 试用额度。

## 范式变更（最重要）
**这不是剪辑软件。没有时间线、没有轨道、没有检查器面板。**
产品是：AI 全自动出片 → 用户通过**多轮对话**修正。像 Lovable / v0 / Claude Artifacts，而不是 Premiere / 剪映。

## 布局
- **最左：极窄项目栏**（默认折叠，~56px）：品牌字标缩写、历史项目缩略图（第 2 期、第 1 期）、「新建」按钮。
- **左：对话流**（约 40% 宽）
- **右：大预览**（9:16 播放器为主角）+ 顶部版本切换（v1 / v2 / v3）+「对比」开关（开启后左右两个版本同步播放）

## 对话流里要呈现的内容（按时间顺序，就是一个真实项目的历史）
1. **设置卡**（已提交，折叠态可展开）：上传的口播「第2期_口播.mov · 3:42」、所选背景「书房」缩略图、字幕样式「刀锋 · 思源黑体」、预估花费 ¥3.84 / 上限 ¥10，按钮「开始出片」已点。
2. **剪辑直播**（已完成，折叠成一段摘要，可点「重播剪辑过程」重新播放动画）：
   - 文字稿逐行出现，气口/口误被划掉（用真实字幕：如「然后呢，嗯，我平时经常在……」划掉「然后呢，嗯，」）
   - 分镜缩略图一张张出现
   - 自检四维分数逐项跳出（版式 9.1 / 层级 8.8 / 动效节奏 8.6 / 品牌一致性 9.3）
   - 结论：「删除 37 处气口 · 12 处口误 · 3:42 → 1:57 · 18 段」
3. **v1 版本卡**：缩略图 + 1:57 + 自检 8.8 + 花费 ¥3.84
4. **用户消息**：带一个时间引用标签「@00:58 对比条卡」+ 文字「这张数据太弱了，加上具体比例，再把开头第二张钩子卡的 ¥0.51 放大」
5. **AI 回复**：确认理解（附两张被引用段的小缩略图），说明要改两处，并给出**可点选的内联选项**（如对比卡的 3 种版式缩略图让用户选一个），用户已选第 2 个
6. **v2 版本卡**：「只重渲了 2 段 · 38 秒 · +¥0.16」，自检 9.0
7. **用户消息**：「背景换成夜景落地窗试试」
8. **AI 正在处理中**（流式状态）：内联展示 10 张背景缩略图里的「夜景落地窗」被选中，进度「抠像合成中 62%」
9. **输入框**：支持在预览上点一下就插入「@时间 + 当前卡片名」标签；有快捷建议 chips（「节奏再快一点」「换一张 B-roll」「字幕换成得意黑」「导出」）；显示本轮预估花费

## 交互（必须可点）
- 点预览画面或暂停时 → 输入框出现「@mm:ss 卡片名」标签
- 切 v1 / v2 → 预览换帧；开「对比」→ 双播放器并排
- 点「重播剪辑过程」→ 剪辑直播动画重新播放（这是惊艳时刻，动效要用心，参考 60fps.design 的精细度）
- 内联选项可点选；输入框可输入并「发送」（假回复即可）
- 导出入口（MP4 1080×1920 / 封面 4:3 + 3:4）放在版本卡或预览顶部，不要做成常驻大面板

## 交付
视口 1440×900，单文件 HTML，图片走 `assets/` 相对路径（WebGL 纹理可 base64）。截图同名 `.png`（可用本机已缓存的 Chromium + 自写 Playwright 脚本，脚本放 scratchpad 自己的子目录，不要改别人的脚本）。自查迭代至少 2 轮：溢出、错位、字体、控制台报错、可读性。
回报：文件路径、form 来自内容哪里、已知缺陷。
