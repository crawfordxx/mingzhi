# 明知AI剪辑 工作台 · 三方向初稿共用设计 Spec

## 产品是什么
明知AI剪辑 是一个开源（MIT）的 **AI 口播剪辑工作台**。用户双击启动器 → 本机起服务 → 自动打开浏览器进入工作台。
用户只录一条口播（竖屏 1080×1920），丢进来，**全自动出片**：
1. 火山 ASR 字级识别 → Claude Opus 判断并删掉气口/口误/重复
2. 换背景：本地 RVM 抠像，用户从 10 张预设虚拟背景里选（书房 / 极简工作室 / 咖啡馆 / 夜景落地窗 / 科技暗色…），或上传、或一句话生成
3. AI 写分镜：上半屏信息卡（数据卡、对比条、网格、终端、知识卡、网页截图）+ 下半屏人像，开头 3 张钩子卡，结尾关注/点赞/收藏 CTA
4. 自动 B-roll：网页截图 > gpt-image-2 生图 > 图库 > 搜索 > Seedance 生视频
5. 转场动画、转场音效、AI 背景音乐（人声压低）
6. 字幕：6–8 套样式预设（字体+描边+关键词高亮色+逐字动效），字体候选：思源黑体、思源宋体、得意黑、霞鹜文楷、站酷快乐体、站酷高端黑、站酷庆科黄油体、阿里巴巴普惠体
7. 品质自检：硬性检查（字幕不撞卡片/安全区、对比度、黑帧、响度 -14 LUFS）+ 视觉模型四维打分（版式/层级/动效节奏/品牌一致性，<8 分自动重做该段，最多 2 次）
8. 封面 4:3 + 3:4
9. 开跑前显示「预估花费 ¥x.xx / 上限 ¥y」，用户点一次确认
10. 出片后按段列出，每段可以用一句话指令重做（如「这张换成对比图」），只重渲染那一段

## 要设计的画面（每个方向都做同一屏，便于横向对比）
**工作台主屏 · 「出片完成」状态**，视口 1440×900，单文件 HTML（可引 Google Fonts 和 cdnjs/jsdelivr 的固定版本库），图片用相对路径 `assets/xxx.jpg`。
必须包含（布局自由，但信息都要在）：
- 顶部导航：项目名「第 2 期 · 高性价比人生指南」、余额/额度（算力余额 ¥36.27（可想 AI））、设置
- 9:16 成片预览播放器（用 assets 里的真实帧，可做成点击段落切换帧 + 假播放进度）
- 管线状态：识别 → 剪口误 → 换背景 → 分镜 → B-roll → 渲染 → 自检，全部完成，每步有耗时；显示「删除 37 处气口 · 12 处口误 · 原片 3:42 → 成片 1:57」
- 分段列表（时间线或卡片列表均可）：至少 8 段，每段显示时间码、字幕原文、用了哪个卡片模板、缩略图、自检分数，以及「一句话重做」入口
- 背景选择器（10 个预设，当前选中「书房」；没有真图的预设用诚实的色调块 + 名称 + 小字「待生成」）
- 字幕样式选择器（≥6 套，用真实中文字体渲染「怎么少花冤枉钱」做预览）
- 自检报告：四维分数 + 硬性检查通过项
- 本次花费：¥3.84 / 上限 ¥10
- 导出按钮（MP4 1080×1920 / 封面）

交互至少做到：点分段 → 预览切到对应帧；点背景/字幕预设 → 选中态切换；「一句话重做」可展开输入框；hover 有精致微交互（参考 60fps.design 的细节水准）。

## 受众与气质
受众：中文自媒体口播博主（零技术背景到半专业），在 1m 距离的笔记本上用。
气质：这是一件**作品级的创作工具**，目标是能拿 Awwwards / FWA / Webby 的水准。专业、克制、有作者意图，不能像后台管理系统，也不能是 AI 默认 slop（紫渐变、emoji 图标、圆角卡片+左边彩条、Inter 做标题、#0D1117+霓虹）。
可读性底线：正文 ≥14px，标签 ≥12px，对比度 ≥4.5:1。
视觉母题建议（可自行推导更好的）：「一镜到底」——一条连续的胶片/时间线贯穿；或「切口」——被剪掉的气口作为可见的切痕。

## 三个方向（每个 subagent 只做自己那一个）
- **A · 暗色专业工具**：Linear / Runway / DaVinci 的气质，深灰（非 #0D1117 深蓝）底 + 一个荧光强调色，呼应用户钩子卡里的荧光黄绿（约 #D4FF3A）。信息密度高，像专业剪辑软件。
- **B · 日式便当网格编辑风**：米白纸感底色、bento 网格、粗衬线中文标题（思源宋体 Heavy / Noto Serif SC 900），像一本设计杂志；黑 + 一个朱红点缀。
- **C · 液态玻璃 + 3D**：Three.js 背景（粒子/体积光/缓慢流动的胶片带），玻璃质感面板，冲击力最强，但必须克制不俗气，文字可读性不能被牺牲。

三版布局骨架必须结构性不同（不能只是换皮）。
