# 明知AI剪辑 · 实施路线图

**Spec:** `docs/DECISIONS.md`（全部产品决策）+ `docs/design/G1-ego-light.html`（选定视觉）+ `docs/design/direction-approved.md`

整个产品拆成 6 个阶段，每个阶段单独一份计划，结束时都能产出可运行、可测试的软件。后一阶段只依赖前一阶段公开的接口与 `project.json` 结构。

| 阶段 | 名称 | 产出（可验证） | 依赖 |
|---|---|---|---|
| **P1** | 精剪核心 | 命令行 `pnpm mingzhi edit 口播.mp4` → 去气口/口误/停顿 + 烧录字幕的竖屏 mp4，以及 `project.json`（文字稿、剪切、字幕） | — |
| P2 | 换背景与分屏 | RVM 本地抠像 + 10 张预设背景 + 色温匹配；输出「下半屏人像」中间件 | P1 |
| P3 | 分镜与成片渲染 | Remotion 卡片/转场模板库（首批 12 个）+ Gemini 分镜 JSON + B-roll（网页截图 / GPT Image / Seedance 排队）+ 钩子卡 + CTA + 背景音乐与音效 + 封面 | P1、P2 |
| P4 | 品质自检与花费控制 | 硬性检查 + Gemini 视觉四维打分、低于 8 分重做该段；预估花费 / 上限 / 降级；可想单并发任务队列 | P3 |
| P5 | 对话式工作台 | 本机服务 + G1 界面：设置卡、剪辑直播、版本卡、@时间引用、多轮修改只重渲受影响段、版本对比 | P1–P4 |
| P6 | 启动器与分发 | 小启动器（首次下载 Node / ffmpeg / Chrome Headless Shell / 模型，断点续传 + 校验 + 国内镜像）、macOS 签名公证、Windows 包、README 中英 | P5 |

## 已验证的技术事实（2026-10-14 实测，计划依赖它们）
- sherpa-onnx-node 1.13.8 + Silero VAD + SenseVoice：117s 音频 1.2s 识别完，带字级时间戳；ITN 会把「五毛一」错转成「01元」→ 关闭 ITN
- 可想 `gemini-3.5-flash` + `reasoning_effort: low` 剪口误准确；`gemini-3.1-flash-lite` 会误删正文，不能用于剪口误
- 可想 Responses + `web_search` 只有 `openai/gpt-5.6-luna` 可用
- 可想生图 ¥0.2/张、Seedance 2.0 Mini ¥2.4/4 秒；套餐并发上限 1
