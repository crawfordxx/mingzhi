# P4 品质自检与花费控制 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 出片前显示预估花费并确认、全程按实际用量记账且不超过上限（超限自动降级）；渲染前用 Gemini 看图给每张卡片打四维分，低于 8 分的卡片重写（最多 2 次）；渲染后做硬性检查（黑帧、爆音、响度、帧率、尺寸、字幕安全区、对比度），结果写进 `project.json`。

**Architecture:** 新增 `CostMeter`（记账：模型用量 × 价格表 + 可想任务返回的 cost），`KexiangClient` 与 `KexiangTaskClient` 都把花费报给它；`estimateCost` 在开跑前给出区间；B-roll 获取已按预算降级（P3b），这里把预算统一交给 `CostMeter`。卡片自检在 compose 之前：逐张渲染卡片在进场、中段、出场前三个时刻的静帧，拼成一张横条交给 `gemini-3.5-flash` 打分，不达标时把评语交回分镜模型重写这张卡（可换模板），再归一化。成片硬检查全部本地 ffmpeg 完成。

**Tech Stack:** 可想 chat completions（`usage` 字段）、`/api/v1/models` 价格表、Remotion `renderStill`、ffmpeg（blackdetect、ebur128、astats）、zod、vitest

**Spec:** `docs/DECISIONS.md`（出片管线第 7 条品质自检、第 8 条花费控制、⚠️ 实测约束、可想 AI 实测记录中「看图自检」一行）。依赖 P3a/P3b/P3c 完成。

## Global Constraints

- 品质自检：硬性检查（字幕不撞卡片/平台安全区、对比度 ≥4.5、无黑帧、无爆音、-14 LUFS、30fps）+ Gemini 视觉四维打分（版式/层级/动效节奏/品牌一致性），任一 <8 重做该段，最多 2 次
- 花费控制：开跑前显示预估花费，点一次确认；每条视频默认上限 ¥10（可调）；超限自动降级（Seedance → 生图 + Ken Burns）；默认只给开头钩子用 Seedance
- 视觉自检模型 `google/gemini-3.5-flash`（实测 15.5 秒，能指出「字幕压住卡片注释」）
- 可想 chat 返回 `usage: { prompt_tokens, completion_tokens, completion_tokens_details.reasoning_tokens }`（实测）；价格表 `GET https://kexiangai.com/api/v1/models` 返回 `{ list: [{ model, input_price, output_price }] }`，单位「元 / 千 token」（实测：gemini-3.5-flash 输入 0.0105、输出 0.063；gpt-5.6-sol 0.028 / 0.14；gpt-5.6-luna 0.0014 / 0.0084），推理 token 按输出计价
- 可想任务查询返回 `cost`（元）；生图约 ¥0.2/张，Seedance Mini 4 秒 ¥2.4
- 平台安全区（抖音/视频号竖屏，1080×1920）：顶部 0–160、底部 1600–1920、右侧 960–1080（点赞栏）不放字幕与关键文字
- 代码注释、报错、commit 用中文；commit `<type>: <描述>`，无署名行；文件 < 400 行；函数 < 50 行；不可变数据

**Interfaces:**
- `src/cost/prices.ts`：`export interface Price { input: number; output: number }`（元/千 token）、`export const FALLBACK_PRICES: Record<string, Price>`（上面实测的三个模型 + `openai/gpt-5.6-luna`）、`export async function loadPrices(cacheFile: string, fetchImpl?: typeof fetch, now?: () => number): Promise<Record<string, Price>>`（缓存 24 小时；请求失败用缓存，再失败用 FALLBACK）
- `src/cost/meter.ts`：
  - `export interface CostEntry { kind: 'chat' | 'task'; model: string; label: string; yuan: number; tokens?: { input: number; output: number } }`
  - `export class CostMeter { constructor(prices: Record<string, Price>, budgetYuan: number); addChat(model: string, usage: unknown, label?: string): CostEntry; addTask(model: string, yuan: number | undefined, label?: string): CostEntry; get total(): number; get entries(): readonly CostEntry[]; canSpend(yuan: number): boolean; remaining(): number }`
  - 未知模型按 FALLBACK 中最贵的价格估算并在 label 加「（价格未知，按上限估）」
  - `usage` 用 zod 安全解析；缺失时记 0 元并在 label 标注「无用量」
- [ ] Steps：测试（价格换算：1000 输入 + 2000 输出 × gemini 价 = 0.0105 + 0.126；推理 token 已含在 completion_tokens 里不重复计；缓存过期与回退；`canSpend` 边界）→ 实现 → `pnpm vitest run tests/cost.test.ts tests/kexiang.test.ts tests/kexiang-task.test.ts && pnpm typecheck` → Commit `git commit -m "feat: 按实际用量记账（价格表缓存、对话与任务花费）"`

- `export function estimateCost(opts: { durationSec: number; bgPrompt: boolean; broll: boolean; maxVideos: number; qa: boolean }): Estimate`
  - 系数（实测为基础，写成具名常量）：剪口误 ¥0.15/分钟；字幕校对 ¥0.05/分钟；分镜 ¥0.05/分钟；B-roll 生图按每 15 秒 1 张 × ¥0.2（high 按每 10 秒 1 张）；Seedance `maxVideos × 2.4`（low 为 0：可能不需要）；背景生图 ¥0.2；卡片自检每张 ¥0.02 × 卡片数（每 6 秒 1 张），重写最多 ×3
- 超出预算时（`high > budget`）CLI 提示「预估最高 ¥x，超过上限 ¥y：将自动降级（不用 Seedance，必要时少生图）」，仍可继续

### Task 3: 成片硬性检查

**Files:**
- Create: `src/qa/hard.ts`、`src/qa/contrast.ts`
- Test: `tests/qa-hard.test.ts`

**Interfaces:**
- `src/qa/contrast.ts`：`export function contrastRatio(fg: string, bg: string): number`（WCAG 2.x 相对亮度，`#RRGGBB`）
- `src/qa/hard.ts`：
  - `export interface HardCheck { id: 'resolution' | 'fps' | 'loudness' | 'truePeak' | 'blackFrames' | 'safeArea' | 'contrast'; ok: boolean; detail: string }`
  - `export async function hardChecks(video: string, layout: { captionCenters: number[] }, palette: { fg: string; bg: string; label: string }[], cfg: AppConfig): Promise<HardCheck[]>`
  - 规则：分辨率 1080×1920；帧率 30；`ebur128` integrated 在 -14±1 LUFS；true peak ≤ -1.0 dBTP；`blackdetect=d=0.5:pix_th=0.10` 无黑段（片尾 0.5 秒内除外）；字幕中心 y（分屏 960、全屏 1400）与上下安全区不冲突、字幕左右边距保证不进入右侧 960–1080（即字幕宽度 ≤ 900 时居中可满足：检查 `CaptionLayer` 的左右 padding 常量）；对比度：卡片调色板（`THEME` 的文字/底色组合与 6 套字幕样式的字/描边）全部 ≥4.5
- [ ] Steps：测试（对比度已知值：黑白 21、`#777777` 对白约 4.48；用 lavfi 生成含 1 秒黑场的视频断言 blackFrames 失败；正常视频通过；-30 dB 正弦断言 loudness 失败）→ 实现 → Commit `git commit -m "feat: 成片硬性检查（尺寸、帧率、响度、峰值、黑帧、安全区、对比度）"`
