# P3b B-roll 素材获取 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 分镜里需要画面的卡片（钩子卡、图片卡、浏览器卡）由 AI 写出「素材需求」，系统按「网页截图 > GPT Image 生图 > Pexels 图库 > Seedance 视频（只给钩子）」的优先级自动取齐素材，落到工作目录，再交给 P3a 的渲染。

**Architecture:** 分镜模式给 `hook`、`photo`、`browser` 三个模板加可选的 `visual` 素材需求（截图：网址或搜索词；生图：英文提示词；视频：提示词，仅钩子）。分镜生成后，`fulfillVisuals` 逐个需求按优先级尝试获取，结果缓存在 `workDir/broll/`（按需求内容哈希命名，重跑不重复花钱），清单写进 `project.json`；拿不到素材的卡片降级（photo → 全屏人像，browser → 无图加载态，hook → 纯色底）。所有可想付费任务走 P2 的串行任务客户端。

**Tech Stack:** Node 22 内置 fetch、可想 Responses API（联网搜索）、Chrome Headless Shell 命令行截图（Remotion `ensureBrowser()` 提供路径）、可想异步任务（GPT Image / Seedance）、Pexels API（可选）、ffmpeg

**Spec:** `docs/DECISIONS.md`（出片管线第 4 条「B-roll 优先级：网页截图 > GPT Image 生图 > 图库（Pexels）> 搜索 > Seedance（只用于关键钩子镜头）」、生图、生视频、联网搜索、⚠️ 实测约束、花费控制）。依赖 P3a 计划 `docs/superpowers/plans/2026-10-15-p3a-storyboard-render.md` 已完成。

## Global Constraints

- B-roll 优先级：网页截图 > GPT Image 生图 > 图库（Pexels）> 搜索 > Seedance（只用于关键钩子镜头）
- 联网搜索：可想 Responses API + `web_search` 工具，**用 `openai/gpt-5.6-luna`**（实测：`POST https://kexiangai.com/api/v1/responses`，`Authorization: Bearer sk-<key>`，体 `{"model":"openai/gpt-5.6-luna","tools":[{"type":"web_search"}],"input":"…"}`，约 9 秒，返回 `output[].content[].text` 与 `output_text`，网址可能只出现在正文里而没有 annotations）
- 截图（实测）：`chrome-headless-shell --screenshot=<png> --window-size=1080,1350 --hide-scrollbars --force-device-scale-factor=1 --virtual-time-budget=8000 <url>`，约 4 秒；浏览器路径用 `@remotion/renderer` 的 `ensureBrowser()` 返回的 `path`
- 生图（实测）：`GPT-Image-2.5-Flare`、`text2img`、`size: "1:1"`、`resolution: "1k"`、`quality: "medium"`、`output_format: "jpeg"`，约 ¥0.2/张、约 20 秒，返回 `service_output.imgUrl`
- 生视频（实测）：`{"modelName":"KVideo2.0-Mini","modelType":"text2video","content":[{"type":"text","text":…}],"ratio":"1:1","duration":4,"resolution":"720p","watermark":false,"generate_audio":false}`，¥2.4/条、约 139 秒，出片 960×960 **24fps（需转 30fps）**，返回 `service_output.videoUrl`
- 可想套餐同一时间只能跑 1 个任务 → 全部走 `KexiangTaskClient`（P2，`src/llm/kexiang-task.ts`）的串行队列
- 花费：每条视频默认上限 ¥10；Seedance 默认最多 1 个镜头、只给开头钩子（P4 再做预估与确认界面）
- Pexels 需要用户自己的 key（环境变量 `MINGZHI_PEXELS_KEY`），没有就跳过这一档；仓库不含任何 key
- 素材文件只放工作目录 `broll/` 下，Remotion 用 `staticFile('broll/…')` 取
- 代码注释、报错、commit 用中文；commit `<type>: <描述>`，无署名行；文件 < 400 行；函数 < 50 行；不可变数据

import { describe, expect, it } from 'vitest';
import { extractUrls, KEXIANG_RESPONSES_URL, searchUrls, SEARCH_MODEL } from '../src/broll/search.js';

describe('extractUrls', () => {
  it('提取正文网址，去掉反引号与末尾标点，去重保序', () => {
    expect(extractUrls('1. `https://a.com/x`，2. https://b.org/y). 再看 https://a.com/x')).toEqual(['https://a.com/x', 'https://b.org/y']);
  });

describe('searchUrls', () => {
  it('调用 Responses + web_search（gpt-5.6-luna），优先 annotations，过滤 pdf/图片', async () => {
    let body: any;
    let url = '';
    const fetchImpl = (async (u: string, init: RequestInit) => {
      url = u;
      body = JSON.parse(String(init.body));
      return new Response(JSON.stringify({ output: [{ type: 'message', content: [{ type: 'output_text', text: '见 https://c.com/z 与 https://d.com/a.pdf', annotations: [{ type: 'url_citation', url: 'https://e.com/1' }] }] }] }));
    }) as unknown as typeof fetch;
    const urls = await searchUrls('k', 'FDE 前置部署工程师', { fetchImpl });
    expect(url).toBe(KEXIANG_RESPONSES_URL);
    expect(body).toMatchObject({ model: SEARCH_MODEL, tools: [{ type: 'web_search' }] });
    expect(String(body.input)).toContain('FDE 前置部署工程师');
    expect(urls).toEqual(['https://e.com/1', 'https://c.com/z']);
  });
  it('非 2xx 报错', async () => {
    const fetchImpl = (async () => new Response('bad', { status: 500 })) as unknown as typeof fetch;
    await expect(searchUrls('k', 'x', { fetchImpl })).rejects.toThrow('500');
  });
});

### Task 4: 按优先级获取素材并写回分镜

**Files:**
- Create: `src/broll/fulfill.ts`
- Test: `tests/broll-fulfill.test.ts`

**Interfaces:**
- Consumes: Task 1 `visualsOf`、`Visual`、`Storyboard`、`normalizeStoryboard`；Task 2 `searchUrls`、`screenshotUrl`；Task 3 `generateImage`、`generateVideo`、`searchPexels`
- Produces:
  - `export interface BrollAsset { key: string; file: string; source: 'screenshot' | 'generate' | 'pexels' | 'video'; url?: string; cost?: number }`
  - `export interface BrollDeps { screenshot(url: string, out: string): Promise<void>; search(query: string): Promise<string[]>; image(prompt: string, out: string): Promise<{ cost?: number }>; video(prompt: string, out: string): Promise<{ cost?: number }>; pexels?(query: string, out: string): Promise<boolean> }`
  - `export interface FulfillOptions { workDir: string; maxVideos: number; budgetYuan: number; onAsset?: (a: BrollAsset | { key: string; failed: string }) => void }`
  - `export interface FulfillResult { storyboard: Storyboard; assets: BrollAsset[]; failures: { shotIndex: number; reason: string }[]; costYuan: number }`
  - `export async function fulfillVisuals(storyboard: Storyboard, deps: BrollDeps, opts: FulfillOptions): Promise<FulfillResult>`
  - `export function visualKey(v: Visual): string`（`sha1(JSON.stringify(v))` 前 12 位）
  - `export function makeDeps(opts: { apiKey: string; task: TaskClient; cfg: AppConfig; pexelsKey?: string }): BrollDeps`

**规则：**
