# P7 出片品质（B-roll 联网找素材、版式与质感升级）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把自动成片从「米色底 + 白卡」提升到影视飓风式的质感：模型读口播规划画面节拍，联网从可商用来源找真实素材（实拍视频、照片、官网截图），视觉模型挑图去重，统一裁切调色加颗粒，用全屏插入、画中画、浮层卡等多种版式呈现；同时重做钩子、片尾、声音，并加整片级自检。

**Architecture:**
- B-roll 从「卡片附属字段」升级为独立流水线：`字幕+分镜 → 视觉节拍规划（beats）→ 多源检索（并行）→ 视觉审片打分 + 去重 → 加工（裁切/选段/调色）→ 分配到镜头 → 授权记录`。新代码在 `src/broll/` 下按职责拆文件：`plan.ts`、`sources/{pexels,pixabay,wikimedia,screenshot,generate}.ts`、`select.ts`、`process.ts`、`credits.ts`，`src/pipeline/broll-step.ts` 改为编排它们。
- 渲染层新增三种镜头版式（`broll` 全屏插入、`pip` 画中画、`overlay` 全屏人物 + 浮层卡）与全片质感层（颗粒、暗角）；分镜规则加多样性与版面约束；钩子、片尾、卡间过渡重做。
- 自检新增整片级指标（静止时长、空白率、模板分布、B-roll 覆盖率、首帧非空、素材复用、音效重复），不达标的局部重做。

**Tech Stack:** TypeScript、zod、Remotion 4.0.531、ffmpeg（lut3d、scdet、thumbnail）、可想 AI（gemini-3.5-flash 视觉与规划、gpt-5.6-luna web_search、GPT Image 2、Seedance）、Pexels/Pixabay API（用户选填 key）、Wikimedia Commons API（免 key）、vitest。

**Spec:** 审片报告 `docs/acceptance/p7-audit.md`（由控制者从 scratchpad 的 quality-audit.md 复制入库，删去含真人的帧引用）第 5–6 节；`docs/DECISIONS.md`；用户 2026-10-16 拍板：授权「只用可商用素材 + 官网截图带来源」，图库 key「设置里选填，不填也能用」，预算「维持 ¥10」。

## Global Constraints

- 品质标准（用户原话）：「目标是达到awwwards、webbyawards、FWA能获奖的品质，通过自我检查，反复提升品质，直到达到那个品质标准为止」；审美对标影视飓风（MediaStorm）的质感与品质
- 授权：只用可商用素材——Pexels License、Pixabay Content License、Wikimedia 的 PD/CC0/CC BY（CC BY 必须署名）；默认排除 NC、ND、BY-SA；官网与新闻页可截图（只截页面与标题区，不截新闻图片本体），画面上标注来源；AI 生成的素材标「AI 生成」；每个项目一份 `credits.json`，导出时生成署名文本
- 图库 key：Pexels、Pixabay 在设置里选填（附注册链接 https://www.pexels.com/api/ 、https://pixabay.com/api/docs/ ），不填时用 Wikimedia + 截图 + AI 生成补足；仓库与安装包不含任何 key
- 预算：默认项目上限 ¥10 不变；B-roll 全流程（检索、审片、兜底生图、可选 Seedance）每 2 分钟片目标 ≤ ¥4，超限按现有降级规则
- 生图：GPT Image 2；视频：Seedance（只做图生视频，不做文生视频）；生图提示词套统一影调模板并带禁用词（hologram、robot、neon、glowing）
- 不出现可识别的真人面孔用于负面语境；不使用品牌 Logo 做装饰
- 不编造数字（沿用现有数字校验）；画面数据只用口播或可溯源的公开数据
- 代码注释、报错、界面文案、commit 中文；commit `<type>: <描述>`，无署名行；文件 < 400 行；函数 < 50 行；不可变数据；测试先行

### Task 1: 素材来源层与授权记录

**Files:** Create `src/broll/sources/types.ts`、`src/broll/sources/{pexels,pixabay,wikimedia}.ts`、`src/broll/credits.ts`；Modify `src/config.ts`（新增 `pixabayKey`，环境变量 `MINGZHI_PIXABAY_KEY`）、`src/broll/generate-media.ts`（生图提示词套影调模板与禁用词）；Test `tests/broll-sources.test.ts`、`tests/credits.test.ts`

**Interfaces:**
- `export interface Candidate { id: string /* 来源:原始id */; source: 'pexels' | 'pixabay' | 'wikimedia' | 'screenshot' | 'generated'; kind: 'video' | 'photo'; thumb: string /* 缩略图 URL 或本地路径 */; url: string /* 原文件 */; width: number; height: number; durationSec?: number; fps?: number; page: string /* 作品页 */; author?: string; license: string; licenseUrl?: string; attributionRequired: boolean; aiGenerated: boolean }`

- `export type Source = (q: SourceQuery, signal?: AbortSignal) => Promise<Candidate[]>`；`pexelsSource(key)`、`pixabaySource(key)`、`wikimediaSource()`（Commons API：`generator=search&gsrnamespace=6&prop=imageinfo&iiprop=url|size|extmetadata`，按 extmetadata 的 LicenseShortName 过滤，排除 NC/ND/BY-SA，CC BY 置 attributionRequired）

- 测试：每个来源用假 fetch 断言请求参数与解析；Wikimedia 许可过滤；Pixabay 缓存命中；署名文本

### Task 2: 视觉节拍规划器

**Files:** Create `src/broll/plan.ts`；Test `tests/broll-plan.test.ts`

**Interfaces:**
- `export const BeatSchema`（zod）：`{ start, end, role: 'illustrate'|'prove'|'locate'|'emote'|'define', kind: 'footage'|'photo'|'screenshot'|'chart'|'ui'|'generated', subject: string, mustShow: string[], avoid: string[], queryEn: string[], queryZh: string[], urlHint?: string, present: 'broll-full'|'split'|'pip'|'overlay', shotSize: 'ECU'|'CU'|'MS'|'WS', motion: 'push-in'|'pan-left'|'pan-right'|'parallax'|'slowmo'|'static' }`
- `export async function planBeats(client, captions: TimedCaption[], storyboard: Storyboard, durationSec: number): Promise<{ beats: Beat[]; dropped: number }>`（gemini-3.5-flash，reasoning_effort low）
- 规则（提示词 + 程序校验）：抽象段落 B-roll 覆盖率 ≥ 30%；每 15 秒至少 1 个真实世界画面（footage/photo/screenshot）；优先口播里的具体名词（产品、机构、地点、动作）；景别不连续相同；`broll-full` 单次 1.5–3.5 秒；beats 不重叠、在片长内；程序修正越界与重叠，过短丢弃
- 测试：假 LLM 输出合法/越界/重叠/过短的 beats；覆盖率与节奏约束的程序校验

### Task 3: 视觉审片打分与去重

**Files:** Create `src/broll/select.ts`、`src/broll/contact-sheet.ts`、`src/broll/dhash.ts`；Test `tests/broll-select.test.ts`

**Interfaces:**
- `export async function contactSheet(candidates: Candidate[], out: string, ffmpeg: string): Promise<string>`（最多 9 个缩略图拼 3×3，每格标号；视频取 3 帧中的中间帧）

- 测试：联系表尺寸与标号；打分解析与 clamp；pickBest 阈值；dHash 对同图缩放/轻压缩鲁棒、对不同图区分

### Task 4: 素材加工（裁切、选段、调色、质感）

**Files:** Create `src/broll/process.ts`、`assets/lut/mingzhi-warm.cube`（项目 LUT，暖中性、低饱和、柔高光；自制，随仓库提供）；Modify `render/`（新增 `render/layers/GrainLayer.tsx`：3–5% 动态颗粒 + 轻暗角，叠在全片最上层、字幕之下）；Test `tests/broll-process.test.ts`

**Interfaces:**
- `export async function processAsset(input: { file: string; kind: 'video'|'photo'; focal: {x;y}; target: { width; height }; fps?: number; durationSec?: number }, out: string, ctx: { ffmpeg; lut: string; whiteBalance?: { r; g; b } }): Promise<{ file: string; durationSec?: number; modified: string[] }>`
  - 按 focal 计算目标裁框（主体落在三分线附近）；分辨率不足以 cover 目标尺寸 ×0.8 时返回 `downgrade: 'pip' | 'split'` 而不硬放大
  - 视频：`scdet` 剔除素材内部剪辑点，选运动平稳的 2–4 秒；60fps 素材放成 0.5× 升格；统一转 30fps、去音轨
  - 统一 `lut3d` + 白平衡微调（向人物背景平均色靠拢，增益限幅 0.9–1.1）
- 测试：裁框计算（主体在角落、分辨率不足降级）；视频选段与帧率；LUT 应用后色彩统计变化方向正确；颗粒层渲染不改变尺寸

### Task 5: 新版式（全屏插入、画中画、浮层卡）与 J-cut

**Files:** Modify `src/storyboard/schema.ts`（layout 增加 `broll`、`pip`、`overlay`）、`src/compose/layout.ts`（各版式的人像变换）、`render/Talk.tsx`、`render/layers/{PersonLayer,CaptionLayer,CardLayer}.tsx`；Create `render/layers/BrollLayer.tsx`；Test `tests/layout.test.ts`、`tests/templates.test.ts`（真实渲染抽帧）

- `broll`：素材 1080×1920 铺满（视频或 Ken Burns 静图，起止裁框由 focal 计算，位移 8–12%，inOut 缓动），人声继续，字幕移到 y≈1400，进入前 2 帧 J-cut（画面晚于声音 2 帧切入）
- `pip`：素材全屏，人物缩进右下圆角 360×480，描边与阴影
- `overlay`：人物全屏，顶部浮玻璃小卡（复用现有卡片模板的紧凑尺寸）
- `split` 升级：上半屏素材铺满 + 底部渐变压暗，信息直接排在图上（不再是米色底 + 小白卡）
- 分段渲染哈希（src/compose/segments.ts）把新版式与素材纳入
- 测试：各版式人像变换；真实渲染抽帧断言字幕位置、PIP 位置、全屏素材铺满无黑边

### Task 6: 分镜多样性、钩子重做、卡间过渡与持续演进

**Files:** Modify `src/storyboard/generate.ts`（提示词）、`src/storyboard/normalize.ts`（或现有规则文件）、`render/templates/{Hook,…}.tsx`、`render/layers/CardLayer.tsx`；Test `tests/storyboard-rules.test.ts`、`tests/templates.test.ts`
